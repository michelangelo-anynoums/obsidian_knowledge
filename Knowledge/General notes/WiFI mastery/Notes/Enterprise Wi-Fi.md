# Enterprise Wi-Fi

## Controllers

**Wi-Fi controllers** are systems that centrally manage many **wireless access points (APs)**.  
They help administrators configure, monitor, and secure the whole Wi-Fi network from **one place**.

## Cloud-Managed Wi-Fi

**Cloud-managed Wi-Fi** allows administrators to manage Wi-Fi devices through the **cloud**.  
They can monitor and configure networks **remotely** without being physically at the location.

## Guest Networks

A **guest network** provides Wi-Fi access to **visitors** without giving them access to the company's internal network.  
It helps protect **internal devices and data**.

## NAC

**NAC (Network Access Control)** controls **which devices can access the network**.  
It can check a device's identity and security status before allowing access.

## Zero Trust

**Zero Trust** means **"never trust, always verify."**  
Every user and device must be **verified and authorized**, even when already inside the network.

## Segmentation

**Segmentation** divides a network into **separate sections**.  
For example, employees, guests, and IoT devices can use different network segments, limiting the damage if one segment is compromised.
