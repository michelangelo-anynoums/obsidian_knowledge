# 11.3 Bandwidth

## 📶 What is bandwidth?

**Bandwidth** is the **range of frequencies** that a communication system can use.

It is calculated as:

$$Bandwidth=fmax−fmin$$

It is usually measured in **Hz (hertz)**.

## 💻 Bandwidth and data capacity

**Higher bandwidth** usually means that a system can carry **more data** in the same amount of time.

- **Low bandwidth** → less data can be transmitted.
- **High bandwidth** → more data can be transmitted.

> **Important:** Bandwidth is not exactly the same as internet speed, but a higher available bandwidth can allow a **higher data rate**.
