# 🖥️ CPU Thermal Interface Materials

> [!summary] Purpose Transfer heat from the CPU to the cooler for efficient cooling.

> [!warning] Even a good CPU can run noticeably hotter if the paste is poor or incorrectly applied.

**Thermal paste (also called TIM – Thermal Interface Material)** is a key part of any PC build because it fills microscopic gaps between the CPU and the cooler, allowing heat to transfer efficiently. 

## 🧊 Types & Differences

|Type|Best use|Main advantage|
|---|---|---|
|**Thermal paste**|Desktop CPU|Best all-round choice; easy to apply|
|**Thermal putty**|GPU VRAM / VRM chips|Fills larger gaps; replaces putty originally fitted|
|**Thermal pads**|VRAM, VRMs, SSDs|Clean, easy to fit; fixed thickness|

> [!important] Rule: Use thermal paste on a standard CPU unless the manufacturer specifies a different material. Putty and ordinary pads are not direct replacements for CPU paste.

## 🛠️ How to apply thermal paste (correct method)

1. **Clean the CPU and cooler base**
    
    - Use isopropyl alcohol (90%+) and a lint-free cloth.  
        
    - Remove all old paste completely.  
        
2. **Apply a small amount**
    
    - The most common method:  
        👉 a **pea-sized dot in the center** of the CPU  
        
    - Do NOT spread it manually in most modern CPUs.  
        
3. **Mount the cooler immediately**
    
    - Press it straight down evenly.  
        
    - Screw it in cross-pattern (diagonal tightening) for even pressure.  
        
4. **Do not overapply**
    
    - Too much paste = worse thermal performance and possible mess.
