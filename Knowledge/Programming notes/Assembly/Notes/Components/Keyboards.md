# ⌨️ Keyboard Types

> [!abstract] Overview Keyboards differ in how their keys work, how they feel when pressed, and how they are designed for typing or gaming.

## 🔩 Mechanical Keyboards

![[Pasted image 20260710100515.png]]

![[keychroncherrymechanicalstandardredswitchgif2-1648889740616.gif]]

A **mechanical keyboard** has a separate mechanical switch under each key. These switches make typing feel more precise and can last a long time.

### Key Features

- **Individual switches:** Each key has its own switch.
- **Durability:** Switches are generally designed for many keystrokes.
- **Repairability:** Some keyboards allow individual switches to be replaced.
- **Customization:** Different switches offer different typing experiences.

**Example:** A gaming keyboard with replaceable mechanical switches.

### Keyboard Examples

- Keychron C2
- Keychron K8
- Corsair K70 RGB Core

## ➖ Linear Switches

![[Pasted image 20260710102037.png|368]]

![[Pasted image 20260710102130.png|381]]

Linear switches move **smoothly from top to bottom**, without a noticeable bump or click.

### Key Features

- **Smooth:** No tactile bump while pressing.
- **Quiet mechanics:** No built-in click mechanism, although the keys still make some noise.
- **Fast feel:** Suitable for rapid, repeated key presses.
- **Common use:** Gaming and general typing.

### Switch Examples

- Cherry MX Red
- Gateron Red

### Keyboard Examples

- SteelSeries Apex Pro
- Keychron V1 with Red switches

> [!tip] Remember **Linear = Smooth.** There is no noticeable bump or click when pressing a key.

---

## 🟤 Tactile Switches

![[Pasted image 20260710103032.png|384]]

![[Pasted image 20260710103101.png|453]]

Tactile switches have a small **bump that you can feel** when pressing a key. This helps you notice when the key activates.

### Key Features

- **Tactile feedback:** You feel a bump during the keystroke.
- **Typing feedback:** Helps you recognize key presses without looking.
- **Versatile:** Suitable for both typing and gaming.
- **Sound:** Usually quieter than clicky switches, depending on the keyboard.

### Switch Example

- Cherry MX Brown

### Keyboard Examples

- Keychron K2 with Brown switches
- Ducky One 3 with Brown switches

> [!tip] Remember **Tactile = Feel the bump.** You get feedback without needing a loud click.

---

## 🔊 Clicky Switches

![[Pasted image 20260710103211.png|402]]

![[Pasted image 20260710103241.png|219]]

Clicky switches provide a noticeable tactile response and an audible **click sound** when pressed.

### Key Features

- **Audible feedback:** Produces a distinct clicking sound.
- **Tactile feedback:** You can feel the key activation.
- **Typing experience:** Some people enjoy the clear feedback while typing.
- **Noise:** Can be distracting in shared offices or quiet rooms.

### Switch Example

- Cherry MX Blue

### Keyboard Examples

- Keychron C2 with Blue switches
- Das Keyboard 4 Professional

> [!tip] Remember **Clicky = Feel the bump and hear the click.**

---

## 🧽 Membrane Keyboards

![[Pasted image 20260710101555.png|523]]

![[Pasted image 20260710101717.png|369]]

![[Pasted image 20260710101839.png|336]]

A **membrane keyboard** uses layers of material and usually rubber domes to register key presses. The keys often feel softer than mechanical keys.

### Key Features

- **Affordable:** Usually cheaper to manufacture.
- **Quiet:** Typically produces less typing noise.
- **Simple design:** Often lightweight and easy to use.
- **Common use:** Office computers, budget keyboards, and many laptops.

**Example:** A basic keyboard used in an office.

### Keyboard Examples

- Logitech K120
- Microsoft Wired Keyboard 600

> [!tip] Remember **Membrane = Simple, affordable, and usually quiet.**

---

## 💡 Optical Keyboards

![[Pasted image 20260710102603.png|382]]

![[Pasted image 20260710102652.png|422]]

An **optical keyboard** uses light to detect when a key is pressed. Instead of relying only on a traditional metal electrical contact, the switch detects a change in a light signal.

### Key Features

- **Light-based detection:** Registers a key press using an optical mechanism.
- **Fast response:** Some designs offer very low input latency.
- **Gaming:** Popular in gaming keyboards.
- **Switch variety:** Can use different switch designs and key feels.

### Keyboard Examples

- Razer Huntsman V3
- Corsair K100 RGB Optical

> [!tip] Remember **Optical = Uses light to detect a key press.**

> [!note] Important Optical keyboards can also be mechanical in feel and construction. _Optical_ describes how the key press is detected, not necessarily how the key feels.

---

## 🖐️ Ergonomic Keyboards

![[Pasted image 20260710102824.png|344]]

An **ergonomic keyboard** is designed to make typing more comfortable by encouraging a more natural hand, wrist, or arm position.

### Key Features

- **Split layouts:** Separate the keys into two sections.
- **Curved layouts:** Position keys to better follow natural hand movement.
- **Comfort:** May reduce awkward wrist positioning during long typing sessions.
- **Adaptation:** Some designs require time to get used to.

### Keyboard Examples

- Logitech Wave Keys
- Microsoft Sculpt Ergonomic Keyboard
- Keychron Q13 Max

> [!tip] Remember **Ergonomic = Designed for a more natural typing position.**

## 🧠 Quick Comparison

|Keyboard Type|Main Feature|Best Suited For|
|---|---|---|
|Mechanical|Individual switches|Typing, gaming, customization|
|Linear|Smooth keystroke|Gaming, rapid key presses|
|Tactile|Noticeable bump|Typing and general use|
|Clicky|Bump and audible click|Typing with clear feedback|
|Membrane|Rubber domes and membrane layers|Budget and office use|
|Optical|Light-based key detection|Gaming and low-latency input|
|Ergonomic|Comfort-focused layout|Extended typing sessions|
