# CPU (Central Processing Unit)

The **CPU** is the **brain of the computer**. It **processes data** and **runs programs**.

## Cores

- **Cores** are the **working parts** inside the CPU.
    
- More **cores** let the CPU do **more tasks at the same time**.
    

## Threads

- **Threads** are **virtual tasks** that a CPU can handle.
    
- More **threads** help the CPU work **more efficiently**.
    

## Clock Speed

- **Clock speed** shows **how fast** the CPU works.
    
- It is measured in **GHz (Gigahertz)**.
    
- A **higher clock speed** usually means **faster performance**.
    

## Cache

- **Cache** is **very fast memory** inside the CPU.
    
- It stores **frequently used data** so the CPU can access it **quickly**.
    

## Integrated Graphics

- **Integrated graphics** is a **graphics processor built into the CPU**.
    
- It can display images and videos **without a separate graphics card**.
    

# Examples

## Intel Core Series

- Popular models: **Intel Core i3**, **i5**, **i7**, and **i9**.
    
- Used in **home**, **school**, and **gaming** computers.
    

## AMD Ryzen Series

- Popular models: **Ryzen 3**, **Ryzen 5**, **Ryzen 7**, and **Ryzen 9**.
    
- Known for **good performance** and **good value**.
