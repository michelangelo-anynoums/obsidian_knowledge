# Rogue APs + Evil Twins

### Rogue Access Points

A **rogue access point (AP)** is an unauthorized Wi-Fi device connected to a network. It can create a **security risk** because attackers may use it to access the network.

### Evil Twin Attacks

An **evil twin** is a fake Wi-Fi network that looks like a real one. An attacker uses it to **trick users into connecting** and may steal their information.

### User Risks

Users may have their **passwords, personal data, or network traffic** stolen. They can also be sent to **fake websites** or download malicious software.

### Defenses

- Use **WPA2/WPA3** and strong passwords.
- Avoid unknown or suspicious Wi-Fi networks.
- Use **VPNs** on untrusted networks.
- Organizations should **monitor for unauthorized APs**.
