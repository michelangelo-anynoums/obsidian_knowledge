# 🧅 Hosting a Tor Website on Linux

> ⚠️ Use this for your own server/lab. A Tor website is called an **onion service**.

## 1. How It Works 🌐

A normal website looks like:

```text
Browser
   ↓
Internet
   ↓
Web server
```

A Tor onion service works differently:

```text
        Tor Network
       /           \
Client ───────────→ Onion Service
                       ↓
                  Web server
```

The server **does not need a public IP address**.

Instead, Tor creates a special `.onion` address and connects visitors through the Tor network.

### 🔐 The important idea

The client does **not connect directly to the server**.

```text
Browser
   ↓
Tor
   ↓
Tor relays
   ↓
Tor rendezvous point
   ↓
Tor
   ↓
Onion service
   ↓
localhost:80
```

Both sides communicate through Tor without revealing the server's normal network location to the visitor.

**Reference:** [How does hidden service work in Tor?](https://bitcoinwiki.org/wiki/Hidden_Service)

---

## 2. Install Tor 🛠️

On Debian/Ubuntu:

```bash
sudo apt update
sudo apt install tor nginx
# Install Tor Browser client
sudo apt install torbrowser-launcher
```

Start the web server:

```bash
sudo systemctl enable --now nginx
# nginx is optional
python3 -m http.server 127.0.0.1 8080
```

You should now have a normal website available locally:

```text
http://127.0.0.1
```

---

## 3. Configure the Onion Service 🧅

Edit Tor's configuration:

```bash
sudo nano /etc/tor/torrc
```

Add:

```text
HiddenServiceDir /var/lib/tor/mywebsite/
HiddenServicePort 80 127.0.0.1:80
```

This tells Tor:

```text
.onion port 80
      ↓
127.0.0.1:80
      ↓
NGINX
```

Restart Tor:

```bash
sudo systemctl restart tor
```

---

## 4. Get Your `.onion` Address 📍

Tor generates the onion address automatically.

On many Debian-based systems:

```bash
sudo cat /var/lib/tor/mywebsite/hostname
```

You'll see something similar to:

```text
abcdefghijklmnopqrstuvwxyz1234567890abcdefghijklmnopqrstuvwxyz.onion
```

That's your website's **onion address**.

---

## 5. Test It 🧪

Open the `.onion` address using **Tor Browser**.

```text
Tor Browser
     ↓
your-address.onion
     ↓
Tor network
     ↓
Your Linux server
     ↓
NGINX
     ↓
Website
```

Your server only needs to be running Tor and the local web server. You don't have to expose port 80 directly to the Internet.

## 🧠 Remember

- 🧅 **Onion service** = website accessible through Tor
    
- 🔒 Server's normal IP is not exposed to visitors
    
- 🌐 Tor handles the connection between visitor and server
    
- 🖥️ NGINX serves the actual website
    
- 📍 The `.onion` address is generated by Tor
    
- 🔗 `HiddenServicePort` connects the onion service to your local web server
