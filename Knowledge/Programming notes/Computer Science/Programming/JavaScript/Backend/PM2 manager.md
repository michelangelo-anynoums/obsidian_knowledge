# 🚀 PM2 — Node.js Process Manager

> ⚙️ PM2 is a process manager for Node.js applications. It keeps applications running, manages processes, monitors resources and handles restarts.

## 📦 1. Installation

```bash
# Install PM2 globally
npm install pm2 -g

# Check version
pm2 -v

# Show help
pm2 --help
```

## ▶️ 2. Start Applications

```bash
# Start an application
pm2 start app.js

# Start with a custom name
pm2 start app.js --name "my-api"

# Start an npm script
pm2 start npm --name "my-app" -- start

# Start in cluster mode
pm2 start app.js -i max
```

## 📋 3. Process Management


```bash
# List running processes
pm2 list

# Show process information
pm2 show my-api

# Restart
pm2 restart my-api

# Stop
pm2 stop my-api

# Delete from PM2
pm2 delete my-api

# Restart all applications
pm2 restart all

# Stop all applications
pm2 stop all

# Delete all processes
pm2 delete all
```

## 📊 4. Monitoring & Logs

```bash
# Live monitoring dashboard
pm2 monit

# Display logs
pm2 logs

# Logs for a specific app
pm2 logs my-api

# Last 100 lines
pm2 logs --lines 100

# Clear logs
pm2 flush

# Process information
pm2 describe my-api
```

## 🔄 5. Automatic Restart

```bash
# Restart when files change
pm2 start app.js --watch

# Restart after memory limit
pm2 start app.js --max-memory-restart 300M

# Set restart delay
pm2 restart my-api --restart-delay=3000
```

## 💾 6. Save & Restore Processes


```bash
# Save current process list
pm2 save

# Restore saved processes
pm2 resurrect

# Remove saved process list
pm2 cleardump
```

## ⚡ 7. Startup on System Boot

```bash
# Generate startup configuration
pm2 startup

# Save running applications
pm2 save
```

> [!abstract] 💡 Run the command generated by `pm2 startup` to configure your operating system's startup service.

## ⚙️ 8. Ecosystem Configuration

Use `ecosystem.config.js` to manage multiple applications.

```js
module.exports = {
  apps: [
    {
      name: "my-api",
      script: "./app.js",
      instances: 2,
      exec_mode: "cluster",
      watch: false,
      max_memory_restart: "300M",
      env: {
        NODE_ENV: "development"
      },
      env_production: {
        NODE_ENV: "production"
      }
    }
  ]
};
```

Run it:

```bash
# Start applications
pm2 start ecosystem.config.js

# Start with production environment
pm2 start ecosystem.config.js --env production

# Restart ecosystem
pm2 restart ecosystem.config.js

# Reload with minimal downtime (cluster mode)
pm2 reload ecosystem.config.js
```

## 📌 9. Quick Reference

|Command|Description|
|---|---|
|`pm2 start app.js`|Start application|
|`pm2 list`|List processes|
|`pm2 show app`|Process details|
|`pm2 restart app`|Restart process|
|`pm2 reload app`|Reload process|
|`pm2 stop app`|Stop process|
|`pm2 delete app`|Remove process|
|`pm2 logs`|Display logs|
|`pm2 monit`|Monitor resources|
|`pm2 save`|Save process list|
|`pm2 resurrect`|Restore processes|
|`pm2 startup`|Configure boot startup|
|`pm2 flush`|Clear logs|
|`pm2 update`|Update PM2 in memory|

## 🧠 Remember

- 🚀 `start` → Run your application.
- 🔄 `restart` → Restart your application.
- ♻️ `reload` → Reload with minimal downtime (cluster mode).
- 🛑 `stop` → Stop your application.
- 🗑️ `delete` → Remove it from PM2.
- 📊 `monit` → Monitor CPU and memory.
- 📋 `logs` → Check application output.
- 💾 `save` → Save process configuration.
- ⚙️ `startup` → Start applications after reboot.

**💡 Tip:** PM2 keeps your Node.js application alive even if it crashes by automatically restarting it.
