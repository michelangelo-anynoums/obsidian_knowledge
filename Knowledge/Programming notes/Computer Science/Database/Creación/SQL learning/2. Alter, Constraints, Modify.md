# 🗄️ SQL Oracle — ALTER, Constraints & MODIFY

> [!abstract] 🎯 Quick lesson Learn how to modify existing tables, manage columns, and apply constraints in Oracle SQL.

---

## 🔧 1. ALTER TABLE

Used to **change the structure of an existing table**.

```sql
-- Add a new column
ALTER TABLE employees
ADD email VARCHAR2(100);

-- Rename a column
ALTER TABLE employees
RENAME COLUMN email TO employee_email;

-- Rename the table
ALTER TABLE employees
RENAME TO staff;
```

## ✏️ 2. MODIFY

Used with `ALTER TABLE` to **change an existing column's definition**.

```sql
-- Change data type / size
ALTER TABLE employees
MODIFY (name VARCHAR2(150));

-- Set a default value
ALTER TABLE employees
MODIFY (salary DEFAULT 1000);

-- Make a column NOT NULL
ALTER TABLE employees
MODIFY (name NOT NULL);
```

💡 `MODIFY` changes a column; it does not create a new one.

## ➕ 3. ADD & DROP


```sql
-- Add a column
ALTER TABLE employees
ADD birth_date DATE;

-- Add multiple columns
ALTER TABLE employees
ADD (
    phone VARCHAR2(20),
    city VARCHAR2(50)
);

-- Delete a column
ALTER TABLE employees
DROP COLUMN birth_date;
```

⚠️ `DROP COLUMN` permanently removes the column and its data.

## 🔒 4. CONSTRAINTS

Constraints are rules that **control the data allowed inside a table**.

|Constraint|Purpose|
|---|---|
|`PRIMARY KEY`|Unique identifier; cannot be NULL|
|`FOREIGN KEY`|Links two tables|
|`UNIQUE`|Prevents duplicate values|
|`NOT NULL`|Requires a value|
|`CHECK`|Validates a condition|

### 🆔 PRIMARY KEY

```sql
CREATE TABLE departments (
    dept_id NUMBER PRIMARY KEY,
    dept_name VARCHAR2(100)
);
```

### 🔗 FOREIGN KEY

```sql
CREATE TABLE employees (
    emp_id NUMBER PRIMARY KEY,
    dept_id NUMBER,

    CONSTRAINT fk_dept
    FOREIGN KEY (dept_id)
    REFERENCES departments(dept_id)
);
```

### 🚫 UNIQUE

```sql
ALTER TABLE employees
ADD CONSTRAINT uq_email
UNIQUE (email);
```

### ❗ NOT NULL

```sql
ALTER TABLE employees
MODIFY (name NOT NULL);
```

### ✅ CHECK

```sql
ALTER TABLE employees
ADD CONSTRAINT chk_salary
CHECK (salary > 0);
```

## 🛠️ 5. ADD & DROP CONSTRAINT

```sql
-- Add a constraint
ALTER TABLE employees
ADD CONSTRAINT pk_employee
PRIMARY KEY (emp_id);

-- Remove a constraint
ALTER TABLE employees
DROP CONSTRAINT chk_salary;

-- Disable a constraint
ALTER TABLE employees
DISABLE CONSTRAINT uq_email;

-- Enable a constraint
ALTER TABLE employees
ENABLE CONSTRAINT uq_email;
```

## 🔄 6. RENAME COLUMN

Change a column's name without changing its data.

```sql
ALTER TABLE employees
RENAME COLUMN name TO full_name;
```

## 🧹 7. TRUNCATE vs DROP vs DELETE

Three commands with very different purposes:

```sql
-- DELETE: Remove rows
DELETE FROM employees
WHERE emp_id = 10;

-- TRUNCATE: Remove all rows
TRUNCATE TABLE employees;

-- DROP: Remove the entire table
DROP TABLE employees;
```

| Command    | Result                   |
| ---------- | ------------------------ |
| `DELETE`   | Removes selected rows    |
| `TRUNCATE` | Removes all rows         |
| `DROP`     | Removes the table itself |

⚠️ `TRUNCATE` and `DROP` are DDL commands and cannot be rolled back in the usual way.

---

## 🧠 8. Remember the difference

```sql
ALTER TABLE employees ADD (...);
```

➕ Create a new column.

```sql
ALTER TABLE employees MODIFY (...);
```

✏️ Change an existing column.

```sql
ALTER TABLE employees DROP COLUMN ...;
```

🗑️ Remove a column.

```sql
ALTER TABLE employees ADD CONSTRAINT ...;
```

🔒 Add a rule to the table.

```sql
ALTER TABLE employees DROP CONSTRAINT ...;
```

🔓 Remove a rule.

---

> [!tip] 💡 Golden rule **ALTER = Change structure**
> 
> **MODIFY = Change column definition**
> 
> **CONSTRAINT = Protect data integrity**
> 
> **DROP = Remove**
> 
> **ADD = Create something new**
