# 🗄️ SQL — SELECT, INSERT & CONSTRAINTS

> [!abstract] 🎯 Goal Retrieve, insert, filter, organise, combine and validate data using SQL.

---

## 🔍 1. SELECT — Retrieve data

Retrieve information from one or more tables.

### Select all columns

```sql
SELECT *
FROM users;
```

### Select specific columns

```sql
SELECT name, email
FROM users;
```

### Use aliases — AS

Rename columns or tables temporarily to make results easier to understand.

```sql
SELECT
    name AS user_name,
    email AS contact_email
FROM users;
```

### Remove duplicates — DISTINCT

Return only unique values.

```sql
SELECT DISTINCT country
FROM users;
```

### Filter results — WHERE

Retrieve rows that match a condition.

```sql
SELECT *
FROM users
WHERE age >= 18;
```

### Multiple conditions — AND / OR / NOT

Combine different conditions.

```sql
-- Both conditions must be true
SELECT *
FROM users
WHERE age >= 18 AND active = TRUE;

-- At least one condition must be true
SELECT *
FROM users
WHERE country = 'Spain' OR country = 'France';

-- Exclude a condition
SELECT *
FROM users
WHERE NOT active = FALSE;
```

Use parentheses to control the order of conditions.

```sql
SELECT *
FROM users
WHERE (country = 'Spain' OR country = 'France')
AND age >= 18;
```

### Compare values — Comparison operators

|Operator|Meaning|
|---|---|
|`=`|Equal to|
|`<>` or `!=`|Not equal to|
|`>`|Greater than|
|`<`|Less than|
|`>=`|Greater than or equal to|
|`<=`|Less than or equal to|

```sql
SELECT *
FROM products
WHERE price <> 100;
```

### Range of values — BETWEEN

Check whether a value falls within a range (inclusive).

```sql
SELECT *
FROM products
WHERE price BETWEEN 10 AND 100;
```

Equivalent to:

```sql
WHERE price >= 10 AND price <= 100;
```

### Match multiple values — IN

Check whether a value matches any value in a list.

```sql
SELECT *
FROM users
WHERE country IN ('Spain', 'France', 'Italy');
```

Exclude multiple values using `NOT IN`.

```sql
SELECT *
FROM users
WHERE country NOT IN ('Spain', 'France');
```

### Pattern matching — LIKE

Search for specific text patterns.

|Pattern|Meaning|
|---|---|
|`'A%'`|Starts with A|
|`'%A'`|Ends with A|
|`'%A%'`|Contains A|
|`'_a%'`|Second character is a|
|`'Jo_n'`|Matches one character at `_`|

```sql
-- Names starting with J
SELECT *
FROM users
WHERE name LIKE 'J%';

-- Emails containing gmail
SELECT *
FROM users
WHERE email LIKE '%gmail%';
```

`NOT LIKE` excludes matching patterns.

### Check missing values — IS NULL

Find records where a column has no value.

```sql
SELECT *
FROM users
WHERE phone IS NULL;
```

Find records where a value exists:

```sql
SELECT *
FROM users
WHERE phone IS NOT NULL;
```

> 💡 **Important:** Never use `= NULL` or `<> NULL`. SQL requires `IS NULL` or `IS NOT NULL`.

### Sort results — ORDER BY

Sort results in ascending or descending order.

```sql
-- Ascending (A-Z / lowest to highest)
SELECT *
FROM users
ORDER BY name ASC;

-- Descending (Z-A / highest to lowest)
SELECT *
FROM users
ORDER BY age DESC;

-- Sort by multiple columns
SELECT *
FROM users
ORDER BY country ASC, age DESC;
```

- `ASC` → Ascending order (default).
- `DESC` → Descending order.

### Limit results — LIMIT

Restrict the number of returned rows.

```sql
SELECT *
FROM users
LIMIT 5;
```

Skip rows using `OFFSET` (syntax supported by PostgreSQL and MySQL).

```sql
SELECT *
FROM users
LIMIT 5 OFFSET 10;
```

This returns 5 rows after skipping the first 10.

### Concatenate values — CONCAT

Combine multiple columns or strings into one value.

```sql
SELECT CONCAT(name, ' ', surname) AS full_name
FROM users;
```

You can also use the concatenation operator `||` in PostgreSQL and several other SQL databases.

```sql
SELECT name || ' ' || surname AS full_name
FROM users;
```

> 💡 **Note:** Concatenation syntax varies between database systems. For example, SQL Server commonly uses `+`.

## 📊 2. GROUP BY — Group data

Group rows that share the same value.

Useful when combined with aggregate functions.

```sql
SELECT country, COUNT(*) AS total_users
FROM users
GROUP BY country;
```

This returns the number of users in each country.

### Aggregate functions

|Function|Purpose|
|---|---|
|`COUNT()`|Count rows or values|
|`SUM()`|Calculate the total|
|`AVG()`|Calculate the average|
|`MIN()`|Find the minimum|
|`MAX()`|Find the maximum|

Examples:

```sql
-- Count users
SELECT COUNT(*)
FROM users;

-- Calculate average age
SELECT AVG(age)
FROM users;

-- Calculate total sales
SELECT SUM(amount)
FROM orders;

-- Find minimum and maximum prices
SELECT MIN(price), MAX(price)
FROM products;
```

### GROUP BY with multiple columns

Group data using more than one column.

```sql
SELECT country, active, COUNT(*) AS total
FROM users
GROUP BY country, active;
```

### Filter groups — HAVING

`HAVING` filters grouped results, while `WHERE` filters individual rows before grouping.

```sql
SELECT country, COUNT(*) AS total_users
FROM users
GROUP BY country
HAVING COUNT(*) > 5;
```

### WHERE vs HAVING

|WHERE|HAVING|
|---|---|
|Filters individual rows|Filters groups|
|Applied before grouping|Applied after grouping|
|Cannot normally use aggregate conditions|Commonly uses aggregate functions|

Example combining both:

```sql
SELECT country, COUNT(*) AS total_users
FROM users
WHERE age >= 18
GROUP BY country
HAVING COUNT(*) > 5;
```

## 🔗 3. JOIN — Combine tables

JOIN allows you to retrieve related information from multiple tables.

Imagine two tables:

**users**

|id|name|
|---|---|
|1|John|
|2|Anna|
|3|Mark|

**orders**

|id|user_id|amount|
|---|---|---|
|1|1|100|
|2|1|50|
|3|2|200|

### INNER JOIN

Returns only records with matching values in both tables.

```sql
SELECT users.name, orders.amount
FROM users
INNER JOIN orders
ON users.id = orders.user_id;
```

### LEFT JOIN

Returns all records from the left table and matching records from the right table.

```sql
SELECT users.name, orders.amount
FROM users
LEFT JOIN orders
ON users.id = orders.user_id;
```

Users without orders will still appear, with `NULL` in the order columns.

### RIGHT JOIN

Returns all records from the right table and matching records from the left table.

```sql
SELECT users.name, orders.amount
FROM users
RIGHT JOIN orders
ON users.id = orders.user_id;
```

### FULL OUTER JOIN

Returns all records from both tables, whether they match or not.

```sql
SELECT users.name, orders.amount
FROM users
FULL OUTER JOIN orders
ON users.id = orders.user_id;
```

> 💡 **Remember:** INNER = matches only, LEFT = everything on the left, RIGHT = everything on the right, FULL = everything from both.

## 🧩 4. Subqueries — Queries inside queries

A subquery is a query nested inside another SQL statement.

### Example — Find users older than the average age

```sql
SELECT *
FROM users
WHERE age > (
    SELECT AVG(age)
    FROM users
);
```

### Example — Find products more expensive than a specific product

```sql
SELECT *
FROM products
WHERE price > (
    SELECT price
    FROM products
    WHERE name = 'Laptop'
);
```

### EXISTS

Check whether a subquery returns at least one record.

```sql
SELECT *
FROM users
WHERE EXISTS (
    SELECT 1
    FROM orders
    WHERE orders.user_id = users.id
);
```

## ➕ 5. INSERT — Add data

Insert new records into a table.

### Insert one record

```sql
INSERT INTO users (name, email, age)
VALUES ('John', 'john@email.com', 25);
```

### Insert multiple records

```sql
INSERT INTO users (name, email, age)
VALUES
    ('Anna', 'anna@email.com', 22),
    ('Mark', 'mark@email.com', 30);
```

### Insert data from another table

```sql
INSERT INTO archived_users (name, email)
SELECT name, email
FROM users
WHERE active = FALSE;
```

**Remember:**

- Specify the columns.
- Values must match the column order.
- Text values use single quotes `' '`.
- Omit columns with default values when you want SQL to assign those defaults.

## 🛡️ 6. CONSTRAINTS — Validate data

Constraints prevent invalid data from entering a table.

### NOT NULL

Value cannot be NULL.

```sql
name VARCHAR(100) NOT NULL
```

### UNIQUE

Prevents duplicate values.

```sql
email VARCHAR(150) UNIQUE
```

### PRIMARY KEY

Unique identifier for each record. It cannot contain NULL values.

```sql
id INT PRIMARY KEY
```

### FOREIGN KEY

Links a record to another table.

```sql
user_id INT,
FOREIGN KEY (user_id) REFERENCES users(id)
```

### CHECK

Enforces a specific condition.

```sql
age INT CHECK (age >= 18)
```

### DEFAULT

Assigns a value automatically if none is provided.

```sql
active BOOLEAN DEFAULT TRUE
```

## 🧩 7. Complete example

Create a table with different constraints:

```sql
CREATE TABLE users (
    id INT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    surname VARCHAR(100),
    email VARCHAR(150) UNIQUE,
    age INT CHECK (age >= 18),
    country VARCHAR(100),
    active BOOLEAN DEFAULT TRUE
);
```

Insert valid data:

```sql
INSERT INTO users
(id, name, surname, email, age, country)
VALUES
(1, 'John', 'Smith', 'john@email.com', 25, 'Spain'),
(2, 'Anna', 'Brown', 'anna@email.com', 22, 'France'),
(3, 'Mark', 'Taylor', 'mark@email.com', 30, 'Spain'),
(4, 'Laura', 'Jones', 'laura@email.com', 28, 'Italy');
```

Retrieve users from Spain or France:

```sql
SELECT
    CONCAT(name, ' ', surname) AS full_name,
    email,
    age,
    country
FROM users
WHERE country IN ('Spain', 'France')
AND age BETWEEN 18 AND 30
ORDER BY age DESC;
```

Count users by country:

```sql
SELECT country, COUNT(*) AS total_users
FROM users
GROUP BY country
HAVING COUNT(*) >= 1
ORDER BY total_users DESC;
```

## 💡 9. Important SQL execution order

Although SQL statements are written in a particular order, the database logically processes the main clauses in this order:

1. `FROM` — Identify the source table(s).
2. `JOIN` — Combine related tables.
3. `ON` — Determine matching conditions.
4. `WHERE` — Filter individual rows.
5. `GROUP BY` — Group the remaining rows.
6. `HAVING` — Filter groups.
7. `SELECT` — Choose columns and calculate expressions.
8. `DISTINCT` — Remove duplicates.
9. `ORDER BY` — Sort the results.
10. `LIMIT / OFFSET` — Restrict or skip results.

> ⚠️ **Remember:** Logical execution order is different from the order in which you write a SQL query.
