# 🗄️ SQL — SELECT, INSERT & CHECKS

> [!abstract] 🎯 Goal Retrieve, insert and validate data using SQL.

---

## 🔍 1. SELECT — Read data

Retrieve information from a table.

```sql
-- All columns
SELECT *
FROM users;

-- Specific columns
SELECT name, email
FROM users;

-- Filter results
SELECT *
FROM users
WHERE age >= 18;

-- Multiple conditions
SELECT *
FROM users
WHERE age >= 18 AND active = TRUE;

-- Sort results
SELECT *
FROM users
ORDER BY name ASC;

-- Limit results
SELECT *
FROM users
LIMIT 5;
```

**Useful keywords:**

- `WHERE` → Filter rows.
- `AND / OR` → Combine conditions.
- `ORDER BY` → Sort results.
- `LIMIT` → Restrict results.
- `DISTINCT` → Remove duplicates.

---

## ➕ 2. INSERT — Add data

Insert new records into a table.

```sql
-- Insert one record
INSERT INTO users (name, email, age)
VALUES ('John', 'john@email.com', 25);

-- Insert multiple records
INSERT INTO users (name, email, age)
VALUES
    ('Anna', 'anna@email.com', 22),
    ('Mark', 'mark@email.com', 30);
```

**Remember:**

- Specify the columns.
- Values must match the column order.
- Text values use single quotes `' '`.

---

## 🛡️ 3. CHECKS — Validate data

Constraints prevent invalid data from entering a table.
### NOT NULL

Value cannot be empty.

```sql
name VARCHAR(100) NOT NULL
```

### UNIQUE

No duplicate values allowed.

```sql
email VARCHAR(150) UNIQUE
```

### PRIMARY KEY

Unique identifier for each record.

```sql
id INT PRIMARY KEY
```

### FOREIGN KEY

Links a record to another table.

```sql
user_id INT,
FOREIGN KEY (user_id) REFERENCES users(id)
```

### CHECK

Enforces a specific condition.

```sql
age INT CHECK (age >= 18)
```

### DEFAULT

Assigns a value automatically if none is provided.

```sql
active BOOLEAN DEFAULT TRUE
```

---

## 🧩 4. Complete example

Create a table with different constraints:

```sql
CREATE TABLE users (
    id INT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(150) UNIQUE,
    age INT CHECK (age >= 18),
    active BOOLEAN DEFAULT TRUE
);
```

Insert valid data:

```sql
INSERT INTO users (id, name, email, age)
VALUES (1, 'John', 'john@email.com', 25);
```

Retrieve the data:

```sql
SELECT *
FROM users
WHERE age >= 18;
```

## ⚡ Quick reference

|SQL|Purpose|
|---|---|
|`SELECT`|Read data|
|`INSERT INTO`|Add data|
|`WHERE`|Filter records|
|`NOT NULL`|Require a value|
|`UNIQUE`|Prevent duplicates|
|`PRIMARY KEY`|Identify records|
|`FOREIGN KEY`|Link tables|
|`CHECK`|Validate conditions|
|`DEFAULT`|Set automatic values|

> 💡 **Remember:** SELECT reads, INSERT adds, and CONSTRAINTS protect your data.
