# Day 4: IP Addressing + Routing

## **IPv4**

- An **IPv4 address** identifies a device on a network.
    
- It is **32 bits (4 bytes)** long.
    
- It is written as **four numbers** separated by dots.
    
- Example: `192.168.1.10`
    

## **Subnetting Basics**

- **Subnetting** divides a network into **smaller networks (subnets)**.
    
- It helps **organize devices** and **reduce network traffic**.
    
- A **subnet mask** shows which part is the **network** and which part is the **host**.
    
- Example subnet mask: `255.255.255.0`
    

## **Gateways**

- A **gateway** connects a **local network** to **other networks**.
    
- Devices send data to the **default gateway** when the destination is outside the local network.
    
- A router is commonly used as the **default gateway**.
    

## **Routing**

- **Routing** is the process of **choosing the best path** for data to travel.
    
- **Routers** forward packets between different networks.
    
- They use **routing tables** to decide where to send each packet.
