# VLANs + NAT + Segmentation

## VLANs (Virtual Local Area Networks)

- A **VLAN** divides one **physical network** into multiple **virtual networks**.
    
- Devices in different **VLANs** are separated unless a router allows communication.
    
- **VLANs** improve **security**, **organization**, and **network performance**.
    

---

## Network Segmentation

- **Network segmentation** means dividing a network into **smaller parts**.
    
- Each segment can have its own **rules** and **security**.
    
- This reduces **network traffic** and limits the spread of attacks.
    

---

## NAT (Network Address Translation)

- **NAT** changes **private IP addresses** into a **public IP address**.
    
- It allows many devices to share **one Internet connection**.
    
- **NAT** also helps hide **internal IP addresses** from the Internet.
    

---

## Think: How would I separate guest Wi-Fi?

- Create a separate **VLAN** for **guest Wi-Fi**.
    
- Keep **guest devices** away from the **main network**.
    
- Allow guests to access only the **Internet**, not **private devices**.
