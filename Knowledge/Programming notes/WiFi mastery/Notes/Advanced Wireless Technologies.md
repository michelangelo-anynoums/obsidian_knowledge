# Advanced Wireless Technologies

## **OFDM (Orthogonal Frequency Division Multiplexing)**

- **OFDM** is a technology that divides a wireless signal into many smaller **subcarriers**.
    
- Each subcarrier sends part of the data at the same time.
    
- It improves **speed** and reduces the effect of **interference**.
    
- Used in standards like **802.11a/g/n/ac/ax**.
    

## **OFDMA (Orthogonal Frequency Division Multiple Access)**

- **OFDMA** is an improved version of OFDM.
    
- It allows multiple users to share the same channel at the same time.
    
- It improves **network efficiency** in crowded areas.
    
- Used in **Wi-Fi 6 (802.11ax)**.
    

## **MIMO (Multiple Input Multiple Output)**

- **MIMO** uses multiple antennas to send and receive data.
    
- It can send multiple data streams at the same time.
    
- It improves **speed**, **range**, and **reliability**.
    
- Used in **Wi-Fi 4 and newer standards**.
    

## **MU-MIMO (Multi-User MIMO)**

- **MU-MIMO** allows a router to communicate with multiple devices at the same time.
    
- It reduces waiting time for users.
    
- It improves performance when many devices are connected.
    
- Used in **Wi-Fi 5 and Wi-Fi 6**.
    

## **Beamforming**

- **Beamforming** focuses the Wi-Fi signal toward a specific device.
    
- It creates a stronger and more direct connection.
    
- It improves **signal strength**, **speed**, and **range**.
    
- Used in modern Wi-Fi networks.
    

# Technology Comparison Table

| Technology      | Main Idea                             | Main Benefit                        |
| --------------- | ------------------------------------- | ----------------------------------- |
| **OFDM**        | Splits data across many subcarriers   | Higher speed and less interference  |
| **OFDMA**       | Shares subcarriers between many users | Better efficiency in busy networks  |
| **MIMO**        | Uses multiple antennas                | Faster and more reliable connection |
| **MU-MIMO**     | Serves multiple devices at once       | Less waiting time                   |
| **Beamforming** | Directs signal toward devices         | Stronger signal and better range    |
