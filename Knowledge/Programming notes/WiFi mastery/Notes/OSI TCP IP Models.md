# Day 2 – OSI + TCP/IP Models

## **OSI Model**

The **OSI Model** explains how **data** moves from one device to another. It has **7 layers**.

The **Open Systems Interconnection (OSI) model** is a conceptual framework developed by the **International Organization for Standardization (ISO)** that standardizes how computer systems communicate over networks.

1. **Physical** – Sends **bits** using cables or **wireless signals**.
    
2. **Data Link** – Moves **frames** between devices on the same network.
    
3. **Network** – Finds the best **path** for data.
    
4. **Transport** – Delivers data **correctly** and **in order**.
    
5. **Session** – Starts, manages, and ends **connections**.
    
6. **Presentation** – Changes data into the correct **format**.
    
7. **Application** – Lets **programs** use the network.
    

---

## **TCP/IP Model**

The **TCP/IP Model** is the model used on the **Internet**. It has **4 layers**.

1. **Link** – Sends data over the local network.
    
2. **Internet** – Moves packets between networks.
    
3. **Transport** – Makes sure data is delivered correctly.
    
4. **Application** – Provides network services to applications.
    

---

## **Where Wi-Fi Fits**

**Wi-Fi** works mainly at:

- **Layer 1 (Physical)** – Sends and receives **radio signals**.
    
- **Layer 2 (Data Link)** – Uses **MAC addresses** and sends **frames** between devices.
    

---

# Focus

## **Layer 1 – Physical**

- Sends **bits**.
    
- Uses **cables**, **fiber**, or **wireless signals**.
    
- Defines electrical, light, or radio signals.
    

### Example:

A laptop sends data through **Wi-Fi radio waves**.

---

## **Layer 2 – Data Link**

- Sends **frames**.
    
- Uses **MAC addresses**.
    
- Detects some **errors**.
    
- Connects devices on the **same local network (LAN)**.
    

### Example:

A **Wi-Fi router** sends a frame to your laptop using its **MAC address**.
