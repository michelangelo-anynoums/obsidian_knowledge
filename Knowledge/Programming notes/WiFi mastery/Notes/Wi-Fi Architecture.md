# Wi-Fi Architecture

## Access Points (AP)

An **Access Point (AP)** is a device that lets **wireless devices** connect to a **network**. It sends and receives **Wi-Fi signals**.

## Wireless Clients

A **wireless client** is any device that connects to Wi-Fi, such as a **laptop**, **phone**, or **tablet**.

## SSIDs

An **SSID (Service Set Identifier)** is the **name of a Wi-Fi network**. It is the name you see when choosing a network to connect to.

## BSS (Basic Service Set)

A **BSS** is a **single Wi-Fi network** created by **one Access Point** and the devices connected to it.

## ESS (Extended Service Set)

An **ESS** is made of **multiple Access Points** with the **same SSID**. It gives **larger Wi-Fi coverage**.

## Roaming

**Roaming** allows a **wireless client** to move from one **Access Point** to another **without losing the connection**. This works inside an **ESS**.
