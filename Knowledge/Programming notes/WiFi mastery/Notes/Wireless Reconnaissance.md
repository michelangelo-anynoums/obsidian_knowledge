# Wireless Reconnaissance

### Passive reconnaissance

**Passive reconnaissance** means collecting information without directly interacting with the target network. It is usually harder to detect.

### Monitor mode

**Monitor mode** lets a wireless adapter listen to Wi-Fi traffic around it. It can receive packets without connecting to a network.

### Packet capture

**Packet capture** means recording wireless network packets. These packets can contain useful information about devices, networks, and communication.

### Beacon analysis

**Beacon frames** are messages sent by Wi-Fi access points. They can reveal information such as the **network name (SSID)**, channel, and security settings.

### Tool: Wireshark

**Wireshark** is a tool used to capture and analyze network packets. It helps you understand **how devices communicate** and identify useful wireless information.
