# **1.4 Estimation**

## **Back-of-the-envelope calculations**

- A **back-of-the-envelope calculation** is a **quick estimate**.
    
- It uses **simple math** and **rough values**.
    
- The goal is to get an **approximate answer**, not an exact one.
    

## **Approximate system behavior**

- **Approximation** helps us understand how a system will work.
    
- We use **estimated values** instead of exact data.
    
- It is useful for **planning** and **finding possible problems**.
    

## **Performance intuition (latency vs throughput)**

- **Latency** = the **time** it takes to finish **one task**.
    
- **Throughput** = the **number of tasks** completed in a certain **time**.
    
- A system can have **low latency**, **high throughput**, or both, depending on its design.
    
- Understanding the difference helps us **measure system performance**.
