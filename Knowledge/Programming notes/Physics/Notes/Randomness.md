# 10.4 Randomness

## Randomness

**Randomness** means that the result cannot be predicted with certainty.

A random process has outcomes that are difficult to predict.

**Example:** Tossing a fair coin:

- Heads → `H`
- Tails → `T`

Each result is unpredictable before the toss.

## Importance in cryptography

**Randomness is critical for cryptography** because secure systems need unpredictable values.

For example, random numbers can be used to create:

- **Encryption keys**
- **Passwords or tokens**
- **Nonces**

If an attacker can predict these values, the security system can become **weak**.

## True vs pseudo-random

### True randomness

**True random systems** produce results from a physical process that is unpredictable.

Examples:

- Thermal noise
- Quantum effects
- Radioactive decay

The result is not generated by a simple mathematical algorithm.

### Pseudo-randomness

A **pseudo-random** sequence is produced by a **deterministic algorithm**.

It looks random, but if you know the **algorithm and starting value (seed)**, you can reproduce the same sequence.

**Example:**

A computer starts with a seed:

`1234`

The algorithm produces:

`7 → 2 → 9 → 4 → ...`

The numbers may look random, but they are actually **predictable if the seed and algorithm are known**.

## Resolved examples

### Example 1 — True or pseudo?

A computer generates numbers using an algorithm and a known seed.

**Answer:** This is **pseudo-random**, because the sequence can be reproduced from the seed.

### Example 2 — Physical randomness

A device measures unpredictable electronic noise to generate random bits.

**Answer:** This can provide **true randomness**, because the values come from a physical process.

### Example 3 — Cryptography

A cryptographic key is generated using predictable values.

An attacker discovers the method and can predict future keys.

**Answer:** The system is **not secure** because cryptography requires **unpredictable randomness**.

### Remember

- **Randomness → unpredictability.**
- Randomness is **critical for cryptography**.
- **True random** → comes from an unpredictable physical process.
- **Pseudo-random** → generated by an algorithm.
- Good cryptographic randomness must be **very difficult to predict**.
