# 4.2 Parallel Circuits

## **What is a parallel circuit?**

A **parallel circuit** is a circuit where the components are connected in **separate branches**.

- There are **multiple paths** for the current.
    
- If one branch breaks, the **other branches still work**.
    

**Example:** The electrical wiring in a house.

---

## **Same voltage across branches**

In a parallel circuit, the **voltage** is the same across every branch.

**Formula:**

```text
V = V₁ = V₂ = V₃
```

Where:

- **V** = voltage (V, volts)
    

**Example:**

If the battery provides **12 V**, then:

```text
V₁ = V₂ = V₃ = 12 V
```

---

## **Current divides**

The **total current** is divided between the branches.

**Formula:**

```text
Itotal = I₁ + I₂ + I₃
```

Where:

- **Itotal** = current from the source
    
- **I₁, I₂, I₃** = current in each branch
    

**Example:**

```text
I₁ = 2 A
I₂ = 3 A

Itotal = 2 A + 3 A = 5 A
```

---

## **Equivalent resistance decreases**

Adding more branches **decreases** the equivalent resistance.

**Formula:**

```text
1 / Req = 1 / R₁ + 1 / R₂ + 1 / R₃
```

For **two resistors**, you can also use:

```text
Req = (R₁ × R₂) / (R₁ + R₂)
```

Where:

- **Req** = equivalent (total) resistance
    
- **R₁, R₂, R₃** = individual resistances
    

**Example:**

```text
R₁ = 6 Ω
R₂ = 3 Ω

Req = (6 × 3) / (6 + 3)
Req = 18 / 9
Req = 2 Ω
```

Notice that **2 Ω** is **smaller** than both **6 Ω** and **3 Ω**.

---

# **Important Facts**

- **Voltage is the same** across every branch.
    
- **Current is divided** between the branches.
    
- **Equivalent resistance decreases** when more branches are added.
    
- If one branch breaks, the **other branches continue working**.

# **Resolved Examples**

## **Example 1: Voltage**

**Question:**  
A battery provides **9 V**. What is the voltage across each of three parallel branches?

**Solution:**

In a parallel circuit, the voltage is the same across every branch.

```text
V = V₁ = V₂ = V₃

V = 9 V
```

**Answer:**

```text
V₁ = V₂ = V₃ = 9 V
```

---

## **Example 2: Current**

**Question:**  
A parallel circuit has two branches.

```text
I₁ = 4 A
I₂ = 2 A
```

Find the total current.

**Solution:**

Use the formula:

```text
Itotal = I₁ + I₂
```

Substitute the values:

```text
Itotal = 4 A + 2 A
Itotal = 6 A
```

**Answer:**

```text
Itotal = 6 A
```

---

## **Example 3: Equivalent Resistance**

**Question:**  
Two resistors are connected in parallel.

```text
R₁ = 4 Ω
R₂ = 4 Ω
```

Find the equivalent resistance.

**Solution:**

Use the formula:

```text
Req = (R₁ × R₂) / (R₁ + R₂)
```

Substitute the values:

```text
Req = (4 × 4) / (4 + 4)
Req = 16 / 8
Req = 2 Ω
```

**Answer:**

```text
Req = 2 Ω
```
