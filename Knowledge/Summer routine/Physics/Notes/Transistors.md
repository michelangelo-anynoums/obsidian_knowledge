## **Transistors**

A **transistor** is a small electronic component that can **control the flow of electric current**.

It can work as:

- An **electronic switch**
    
- An **amplifier** (increases signals)
    

Modern computers contain **billions of transistors** because they are the basic building blocks of CPUs.

**Example:**

A light switch controls electricity in a house.  
A transistor does the same thing, but much faster and at a microscopic scale.

- **N-type**: Doped to have extra **electrons** (negative carriers). Think "N" for **Negative**.
    
- **P-type**: Doped to have extra **holes** (positive carriers). Think "P" for **Positive**.

## **Electronic switch**

A transistor can act like a very small **ON/OFF switch**.

It has two main states:

**1. ON state**

- Current can flow.
    
- It represents **1** in digital systems.
    

**2. OFF state**

- Current cannot flow.
    
- It represents **0** in digital systems.
    

A transistor can switch between these states **billions of times per second**.

**Simple idea:**

```
Input signal → Transistor → Current ON/OFF
```

## **Basis of logic gates**

Logic gates are electronic circuits that perform operations using **0 and 1**.

They are made using combinations of transistors.

Common logic gates:

- **AND gate** → output is 1 only when all inputs are 1.
    
- **OR gate** → output is 1 when at least one input is 1.
    
- **NOT gate** → changes 1 into 0 and 0 into 1.
    

**Example: AND gate**

Two transistors can be connected so that current flows only when both are ON.

```
Input A = 1
Input B = 1

Output = 1
```

If one transistor is OFF:

```
Input A = 1
Input B = 0

Output = 0
```

## **Builds all modern CPUs**

A **CPU (Central Processing Unit)** is made from millions or billions of transistors.

Transistors create:

- Logic operations
    
- Memory circuits
    
- Calculations
    
- Data processing
    

The more transistors a CPU has, the more operations it can usually perform.

**Example:**

A modern processor uses billions of tiny transistor switches to execute programs, games, and calculations.

# Simple physics equations

The current controlled by a transistor can be described using:

**Current:**

I = Q / t

Where:

- **I** = electric current (A)
    
- **Q** = electric charge (C)
    
- **t** = time (s)
    

Electrical power:

P = V × I

Where:

- **P** = power (W)
    
- **V** = voltage (V)
    
- **I** = current (A)

# Simple resolved examples

## **Example 1: Transistor as a switch**

**Question:**  
A transistor receives an input signal of 1. Is the transistor ON or OFF?

**Solution:**

- Input = 1 means the control signal is active.
    
- The transistor allows current to flow.
    

**Answer:**

The transistor is **ON** and represents digital value **1**.

---

## **Example 2: Power calculation**

**Question:**  
A transistor circuit works with 5 V and a current of 0.2 A. What is the power?

**Formula:**

P = V × I

**Calculation:**

P = 5 V × 0.2 A

P = 1 W

**Answer:**

The circuit uses **1 watt** of power.

---

## **Example 3: Logic gate**

**Question:**  
An AND gate has two transistor inputs:

Input A = 1  
Input B = 0

What is the output?

**Solution:**

An AND gate needs both inputs to be 1.

1 AND 0 = 0

**Answer:**

The output is **0**.

- Transistors create **logic gates** using 0 and 1.
    
- Millions or billions of transistors form modern **CPUs**.
    
- Transistors are the foundation of modern electronics and computers.
