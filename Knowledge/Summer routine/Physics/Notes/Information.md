# 10.1 Information

## Information

**Information** is a way of reducing **uncertainty** about something.

For example:

- Before looking outside, you do not know the weather.
- If someone tells you _“It is raining”_, your uncertainty is reduced.
- Therefore, you have received **information**.

In physics and computer science, information can be measured.

## Bits as the basic unit

The **bit (binary digit)** is the basic unit of information.

A bit can have only **two possible values**:

`0` or `1`

One bit can answer a question with **two possible answers**.

**Example:**

> Is the lamp ON?

- `0` → No
- `1` → Yes

### Important idea

More possible choices require **more bits**.

For `N` equally possible choices:

$$I=log⁡2(N)I = \log_2(N)$$

where:

- $I$ = information in **bits**
- $N$ = number of possible choices

**Example:**  
If there are 4 possible choices:

$$I=log⁡2(4)=2bitsI=\log_2(4) =2\text{bits}$$

So, **2 bits** are needed to represent 4 equally possible choices.

### Remember

- **Information = reduction of uncertainty.**
- **Bit = basic unit of information.**
- One bit has **two possible values: 0 or 1**.
- For $N$ equally likely possibilities: **$I=\log_2(N)$**.
