
# Mechanical keyboard

![[Pasted image 20260710100515.png]]

![[keychroncherrymechanicalstandardredswitchgif2-1648889740616.gif]]

- Each key has an **individual switch**.
- **Longer lifespan** than membrane keyboards.
- **Easier to repair** because switches can be replaced.

# Membrane Keyboards

![[Pasted image 20260710101555.png|523]]

![[Pasted image 20260710101717.png|369]]

![[Pasted image 20260710101839.png|336]]

- Use **rubber dome switches** under the keys.
- **Quiet** when typing.
- **Low cost**.
- Common in **laptops** and **office keyboards**.

**Example:** A basic office keyboard.

**Keyboard example to buy:**

- **Logitech K120**
- **Microsoft Wired Keyboard 600**
